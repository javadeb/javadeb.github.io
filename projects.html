Projects

  • Microwave Imaging System for Breast Cancer Detection
    Developed a microwave-based imaging system using time-reversal techniques for detecting tumors based on dielectric contrast in biological tissues.

  • Neural Network Aided Channel Extrapolation
    Designed a neural-network-assisted GPOF algorithm to estimate downlink channel characteristics from uplink data in FDD Massive MISO systems.

  • Microwave Heating and Bacterial Inactivation
    Simulated electromagnetic heating of food materials and analyzed energy absorption in water, proteins, and bacteria using dielectric models.

  • Permittivity Extraction Tool (Python GUI)
    Built a graphical interface to extract dielectric properties from S-parameter measurements using the Nicolson-Ross method.

  • Millimeter-Wave Channel Modeling
    Developed ray-tracing simulations for mmWave propagation and channel estimation in complex environments.

  • Smart Traffic Sign Concept
    Proposed an intelligent traffic sign system for autonomous driving using RF sensing and communication technologies.
