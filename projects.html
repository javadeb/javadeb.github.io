Projects

Research and engineering projects in microwave systems, millimeter-wave propagation, wireless communication, machine learning for RF systems, biomedical sensing, and electromagnetic simulation.

Microwave Imaging System for Breast Cancer Detection
Developed a microwave-based imaging system using time-reversal techniques for detecting tumors based on dielectric contrast in biological tissues. The project focused on biomedical microwave sensing, inverse electromagnetic problems, and non-invasive diagnostics.
Neural Network Aided Channel Extrapolation
Designed a neural-network-assisted GPOF algorithm to estimate downlink channel characteristics from uplink data in FDD Massive MISO systems. The project combined machine learning, signal processing, and wireless channel extrapolation.
Microwave Heating and Bacterial Inactivation
Simulated electromagnetic heating of food materials and analyzed energy absorption in water, proteins, bacteria, and moist food materials using dielectric property models and RF simulations.
Permittivity Extraction Tool (Python GUI)
Built a graphical Python interface to extract dielectric properties from measured S-parameters using the Nicolson-Ross method, TRL calibration, and microwave material characterization techniques.
Millimeter-Wave Channel Modeling
Developed ray-tracing simulations and quasi-deterministic propagation models for millimeter-wave wireless communication systems, including RCS-based scattering analysis and statistical channel characterization.
Smart Traffic Sign Concept
Proposed an intelligent traffic sign system for autonomous driving applications using RF sensing, wireless communication, and smart electromagnetic detection techniques.
Active Dual-Beam Phased Array Antenna System
Designed and developed a dual-beam phased-array antenna system for satellite communication applications, including beamforming networks, active RF chains, and array optimization techniques.
RCS Simulator Accelerated by Machine Learning
Developed a machine-learning-assisted electromagnetic simulator for accelerating bistatic radar cross-section calculations using Physical Optics-Geometrical Optics methods combined with neural network prediction models.
